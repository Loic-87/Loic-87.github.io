# SEO — 3 offres d'emploi ciblées et mots-clés à intégrer

## Les 3 offres

1. **Ingénieur d'études et développement front** — Lab5com (via WeLoveDevs)
   CDI, Boulogne-Billancourt, télétravail hybride, 35-45k€/an, juniors acceptés.
   Stack : JavaScript, Node.js, React.

2. **Développeur JS Full-Stack Junior (H/F)** — Basikon (via Welcome to the Jungle)
   CDI, Paris, télétravail occasionnel, 35-42k€/an.
   Plateforme SaaS low-code (secteur finance/crédit). Profil recherché : "esprit analytique, structuré et autonome", "à l'écoute, curieux(se) et orienté(e) solution".

3. **Web Tools Programmer (H/F/NB)** — Ubisoft (via LesJeudis)
   CDI, Paris, présentiel. Secteur **jeu vidéo**.
   Stack : React, Vue.js, Angular, TypeScript, JavaScript, Python, CI/CD, HTML/CSS, UX Design.
   Profil recherché : "autonomie, curiosité et esprit d'initiative", "bonne capacité à collaborer dans un environnement multidisciplinaire".

## Analyse des mots-clés

**Termes techniques récurrents** : React, JavaScript / TypeScript, Node.js, Full-Stack, Front-end, API REST, CI/CD, HTML/CSS.

**Vocabulaire sectoriel** : "développeur JS full-stack", "intégration web", "plateforme SaaS", "architecture web moderne", et pour l'offre Ubisoft : "jeu vidéo", "gameplay", "outils pour créateurs" — un vocabulaire qu'on peut légitimement utiliser vu ton intérêt pour le secteur.

**Combinaisons géographiques** : Paris, Île-de-France (Boulogne-Billancourt). À utiliser dans les métadonnées si tu cibles cette zone (ex. "développeur full-stack junior Paris").

**Soft skills valorisées** : **autonomie**, **curiosité**, esprit d'initiative, esprit analytique et structuré, orienté solution, capacité à collaborer en environnement multidisciplinaire.

> 🎯 Constat utile : les soft skills demandées sur 2 des 3 offres (autonomie, curiosité) sont exactement les traits que tu as choisis pour ton pitch personnel (acte 5). Ce n'est pas un hasard à exploiter — ça veut dire qu'on peut réutiliser la même formulation entre le pitch et les descriptions de compétences, pour un message cohérent sur tout le site.

## Où injecter ces mots-clés (naturellement, sans bourrage)

- **`<title>`** : "Loïc Le Faucheur — Développeur Full-Stack Junior React | Portfolio"
- **meta description** : mentionner "développeur full-stack junior", "React", et éventuellement la zone géo si pertinente
- **H1 de la page d'accueil** : reprendre "développeur full-stack junior" + une touche personnelle (gaming/moto)
- **H2 des sections** : "Compétences techniques" → citer React, JavaScript, Node.js explicitement plutôt que des termes vagues
- **Descriptions de projets** : réutiliser "autonomie", "curiosité" dans les sections "Compétences développées" des fiches (déjà en partie fait naturellement)
